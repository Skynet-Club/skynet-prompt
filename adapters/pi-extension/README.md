# pi 抽屉扩展

由 `pi` 自动加载（`package.json → pi.extensions`），不需要单独安装。

## 交互

在 pi 的输入框里：

- 在任意位置输入 `；；`（兼容 `;;`）：立即打开抽屉（不要求行首）
- `↑↓`：左列选类目；右列选条目
- `→`：进入条目列表；`←`：回到类目
- `Enter`：把当前条目的中文原文放进编辑器，**不发送**
- `Esc`：关闭，不插入

也可以输入 `/psup` 打开同一个抽屉。

## 数据

直接读包内 `content/index.json` 与 `content/items/<id>/{zh,en}.txt`，
正文逐字节，不经过网络，也不依赖 `psup` 在 PATH 里。

## 边界

- 光标前是 `;;` 或 `；；` 就触发，位置不限
- 触发后两个分号会被替换成选中的正文；`Esc` 取消则移除这两个分号
- 插入的是 `zh` 原文，不做改写、截断或加前缀
- 插入后停在编辑器，需要你自己按 Enter 发送
